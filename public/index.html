Why Prefill?

When you send a prompt to an AI model, it works in two steps. First it reads your whole prompt at once. That's prefill. Then it writes the answer one token at a time. That's decode. Every answer starts with prefill, so we named ourselves after it.

Prefill

Reads your whole prompt at once.

  • Limited by GPU compute
  • Sets the wait for the first word
  • Longer prompts take longer

Decode

Writes the answer one token at a time.

  • Limited by memory speed
  • Sets how fast the answer streams
  • Longer answers take longer
